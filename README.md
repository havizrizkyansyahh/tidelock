TIDELOCK is a first-person descent arcade game: pilot a pressure skiff down a lightless trench, fire sonar pulses to reveal the cave and stun the drifters in it, gather spore clusters for air and score, and decide at each beacon whether to surface or dive deeper.

## Run it

```sh
node serve.ts --port 8123   # then open http://localhost:8123
```
